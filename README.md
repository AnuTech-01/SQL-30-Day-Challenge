## 🧠 What I Learned in 30 Days

### Week 1 — Basics
- How to fetch data using SELECT, FROM, WHERE
- Filter data using AND, OR, NOT operators
- Sort and limit results using ORDER BY, LIMIT
- Aggregate functions like COUNT, SUM, AVG, DISTINCT
- Group data using GROUP BY and HAVING
- Handle missing values with NULL, IS NULL, IS NOT NULL

### Week 2 — Intermediate
- Combine tables using INNER, LEFT, RIGHT, FULL OUTER JOIN
- Write subqueries inside SELECT and WHERE
- Use CASE WHEN for conditional logic
- Manipulate strings using UPPER, LOWER, CONCAT

### Week 3 — Advanced
- Work with dates using DATE functions
- Analyze data using Window Functions and PARTITION BY
- Write clean reusable code using CTEs
- Create Views for saving complex queries
- Automate tasks using Stored Procedures

### Week 4 — Real World
- Optimize slow queries for better performance
- Use Indexes to speed up database searches
- Solved 3 real-world Case Studies (Ecommerce, HR, Sales)
- Practiced 20+ SQL Interview Questions
- Built Final Project — Complete Business Analysis
